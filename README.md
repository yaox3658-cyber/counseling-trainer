# 心理咨询能力训练 · 来访者模拟

一款 **Electron 桌面应用**，用于训练心理咨询的基本功与流派技术。内容框架基于
杰拉德·科里（Gerald Corey）《心理咨询与治疗的理论及实践》（*Theory and Practice of
Counseling and Psychotherapy*）**第 10 版**（中文版）整理。

---

## 核心玩法

1. **中间的动画来访者**：一个会随情绪变化的 SVG 角色，情绪包括平静、焦虑、悲伤、
   愤怒、恐惧、困惑、崩溃、释然等。来访者逐字「开口」说出他的困扰。
2. **下方是你的输入框**：读完来访者的话，输入你的回应（或点「4 选 1」模式从四个
   选项中挑选）。
3. **即时评分**：系统依据微技巧规则引擎对你的回应打分，给出——
   - 总分（0–100）与等级（优秀/良好/合格/需改进）
   - 用到了哪些**有效技巧**（共情、开放式提问、情感反映、重述、具体化…）
   - 踩了哪些**新手误区**（直接给建议、评判、贴标签、过早安慰…）
   - 一条**下一步建议** + 该流派的**参考答案**与解析
   - 对应的**教材章节引用**

## 三种训练重点（应用内可切换）

- **通用微技巧**：倾听、共情、开放式提问、情感反映、重述、具体化、积极关注等基本功。
- **核心三大流派**：以人为中心（罗杰斯）、认知行为（贝克 / 埃利斯）、精神动力与阿德勒。
- **全书流派覆盖**：精神分析、阿德勒、存在主义、以人为中心、格式塔、行为、认知行为、
  现实疗法、女权主义、后现代（焦点解决 / 叙事）、家庭系统等 12 个流派。

## 其他功能

- **技能雷达图**：可视化各微技巧的累计掌握度。
- **进度与历史**：会话记录、平均分、练习次数、连续天数；错题可回看。
- **学习资料库**：12 个流派的核心概念 + 微技巧词条 + 全书蒸馏知识库（详细词条）。
- **可选大模型**：在「设置」里填 API Key，可把自由文本评分升级为深度点评，
  并在脚本案例结束后开启「自由续聊」（AI 扮演来访者继续对话）。

## 本次新增功能（v1.1）

- **多版本参考答案**：每轮除了原有的标准参考答案，还内置了 3 个不同流派/取向的
  参考答案（以人为中心 / 认知行为 / 焦点解决 / 精神动力等），点击「参考答案」面板
  即可展开对照；启用大模型后还能点「🤖 大模型生成更多参考答案」实时再生成 2–3 个。
- **案例轮次扩充**：12 个脚本案例由原来的 3–4 轮扩充到 **5–6 轮**，补全
  「建立关系 → 深入探索 → 干预 → 巩固/结束」的完整咨询弧线。
- **两个「人工智能」案例**（案例列表置顶）：
  - **🤖 AI 教学伙伴**：精通全书 12 流派 + 伦理基础 + 历史案例，可自由提问、出题、
    点评、扮演来访者。离线时退化为「本地知识库检索」。
  - **🤖 AI 复杂来访者**：同时承载抑郁、焦虑、成瘾与关系冲突的复合来访者，训练你
    综合运用多流派技术自由对话。离线时退化为一段脚本化迷你对话。
- **🛤️ 全流程咨询 · 过关模式**（顶栏第 4 个标签页）：按真实咨询「了解 → 干预 →
  帮助来访者」的完整流程，分 **5 关**（建立关系与知情同意 → 评估与个案概念化 →
  目标设定 → 干预 → 巩固与结束/随访），贯穿一位复合来访者，逐关过关、未达标可重试，
  每关都带**非常详细的知识背景**（教材 + 权威教学/真实案例）与督导师点评。
  进度自动保存于本机。
- **📚 全书蒸馏知识库**：把 Corey《心理咨询与治疗的理论及实践》第 10 版全书
  （15 章、12 大流派、关键微技巧）蒸馏成 **28 条结构化词条**（起源 / 人性观 /
  核心概念 / 目标 / 咨访关系 / 技术 / 斯坦 Stan 与格温 Gwen 案例 / 局限）。
  「学习资料」区可逐条浏览；「AI 教学伙伴」的离线检索升级为调用这份详细词条库，
  在线时由 claude-opus-5 依据同一知识框架给出章节目录级的可靠讲解。

> 所有新增内容均为**本地预置、离线可用**；大模型仅作为可选增强（在线生成参考答案、
> 自由对话、过关深度点评）。

## 本次新增功能（v1.2 · 融入课程教材）

把一门大学课程讲义《心理咨询技术与实务》融入应用：

- **🎓 课程教材知识库**（`course-knowledge.js`）：把三份讲义蒸馏成 **16 条结构化词条**——
  - 实务(1)·导论：课程定位、心理咨询是什么/不是什么、定义与特征、vs 心理治疗（含《精神卫生法》与灰色地带）、能做什么/不能做什么、ACA 定位、咨询设置（预约/场所/时间/收费/伦理五原则）、三种形式；
  - 实务(2)·评估性会谈：三个基本阶段、沟通模式「听-说-问-引」、共情性倾听（冰山模型/听的误区）、共情性反馈（说的误区/共情定义）、教学案例集总览。
  在「学习资料」新增一栏逐条浏览，并接入「蒸馏问答」「AI 教学伙伴」的离线检索。
- **🗂️ 12 个可训练对话案例**（`course-cases-1.js` / `course-cases-2.js`）：把《教学案例集》里的
  12 个真实来访者（七七、小芸、小成、小萍、小陈、小欣、小梅、小刘、小李、小丽×2、小东）
  改编为 **5 轮脚本化对话案例**，进入「选择案例」列表可实际练习并规则评分；其中 3 例
  （小刘、小丽·高二、小东）涉及自伤/自杀风险，专门用于训练**安全评估与危机干预**的规范做法。
- 全部沿用「追加式」加载，未改动 `scoring.js` 评分引擎与「待改进」面板。

> 12 个新案例同样做了脱敏与匿名化，人物为虚构，仅用于教育训练；涉及危机的案例中，
> 参考答案示范的是「直接而温和地评估风险 + 制定安全计划 + 转介」的正确做法，不构成临床督导。

## 安装与运行

```bash
cd counseling-trainer
npm install
npm start
```

> **中国大陆加速**（Electron 二进制下载较慢时）：
>
> ```bash
> npm config set electron_mirror https://npmmirror.com/mirrors/electron/
> npm install
> npm start
> ```

无需联网即可离线使用（案例库 + 规则评分全部本地运行）。

## 目录结构

```
counseling-trainer/
├── package.json
├── main.js            # Electron 主进程（窗口 + 大模型代理请求）
├── preload.js         # 上下文隔离桥
├── README.md
└── renderer/
    ├── index.html        # 界面结构
    ├── styles.css        # 样式与主题（含暗色模式）
    ├── avatar.js         # 动画来访者（情绪表情切换）
    ├── cases.js          # 案例库 + 12 流派知识库
    ├── extra-turns-1.js  # 案例 1–6 扩展轮次（补全咨询弧线）
    ├── extra-turns-2.js  # 案例 7–12 扩展轮次
    ├── alt-answers.js    # 原有轮次的多版本参考答案（离线预置）
    ├── ai-cases.js       # 两个「人工智能」案例（教学伙伴 / 复杂来访者）
    ├── book-knowledge.js # 全书蒸馏知识库（28 条结构化词条 + 离线检索）
    ├── omnibus.js        # 把扩展轮次 / 多版本答案 / AI 案例合并进案例库
    ├── workflow.js       # 全流程咨询 · 5 关卡数据（含详细知识背景）
    ├── scoring.js        # 微技巧规则评分引擎
    ├── llm.js            # 大模型调用封装（可选）
    └── app.js            # 主逻辑（交互、进度、雷达、AI 对话、过关、设置）
```

## 大模型配置（可选）

打开应用 → 右上角「⚙ 设置」：

| 字段 | 说明 |
| --- | --- |
| 服务商 | `Anthropic`（Claude）或 `OpenAI 兼容`（DeepSeek / 月之暗面 / 通义 / GLM …） |
| Base URL | OpenAI 兼容接口的地址，如 `https://api.deepseek.com/v1` |
| 模型 | 如 `claude-opus-5`（推荐，最强）、`deepseek-chat`、`gpt-4o-mini` |
| API Key | 仅保存在**本机** localStorage，不会上传 |

## 内容来源与说明

- 案例均改编自教科书中的典型临床情境与斯坦（Stan）贯穿案例，**已做脱敏与匿名化处理**，
  人物为虚构，不指向任何真实来访者。
- 流派章节号对应 Corey 第 10 版中文版目录（第 4–14 章）。
- 本应用仅用于**教育与自我训练**，不构成临床督导、诊断或治疗建议。

## 参考书目

- Corey, G. (2017). *Theory and Practice of Counseling and Psychotherapy* (10th ed.). Cengage.
- 中译本：《心理咨询与治疗的理论及实践》（第 10 版），石林等译，中国轻工业出版社。
